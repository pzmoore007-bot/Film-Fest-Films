# Film Fest Films Landing Page

A responsive, single-page website concept for FilmFestFilms.com.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive design
- `script.js` — mobile navigation and minor interactions
- `favicon.svg` — simple FFF favicon

## Preview
Open `index.html` in any modern browser.

## Before launch
1. Replace the placeholder `@filmfestfilms.com` email addresses with real inboxes.
2. Add a privacy policy and terms page if you collect leads or user data.
3. Connect the CTA forms/buttons to your preferred CRM or email service.
4. Replace placeholder screening-room artwork with approved film stills once you have rights.
5. Consider adding investor deck and filmmaker submission links when those materials are ready.

## Hosting
This site can be uploaded to most static hosts, including traditional cPanel hosting, Netlify, Vercel, Cloudflare Pages, GitHub Pages, or an S3-style static host.
